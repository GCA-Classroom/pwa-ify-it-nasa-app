PWA-ify It — Reference Starter
This is a completed version of the NASA Space Explorer App (Project 7), provided as a clean reference for the PWA-ify It LevelUp.
Most students should work in their own Project 7 repo, not this one, you're extending the app you already built. This repo exists as a fallback if your own project isn't in a working state, and as a reference to compare against if you get stuck.
Getting started
Open this repo in a Codespace
Right-click index.html → "Show Preview" (or use the Live Server button in the status bar) to run it locally
Follow the LevelUp videos on the course platform to add the PWA layer: manifest, service worker, install prompt, and notifications
Full assignment instructions and the rubric are on the course platform, not here.
